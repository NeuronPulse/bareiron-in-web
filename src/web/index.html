关于

bareiron in web 把 bareiron（纯 C 的 Minecraft 1.21.8 服务器）编译为 WebAssembly，在浏览器内运行； 并通过 tailscale-web 在浏览器内运行一个 Tailscale 节点，使外部客户端可直连，无需自建中继。

提示：当前构建未实现浏览器内控制台输入；启动后请使用原生 Minecraft 客户端连入。
